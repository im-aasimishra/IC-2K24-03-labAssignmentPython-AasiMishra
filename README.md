## How to Run the Programs

### For Python Files

1. Clone the repository:

   ```bash
   git clone https://github.com/im-aasimishra/IC-2K24-03-labAssignmentPython-AasiMishra.git
   ```

2. Open the repository in VS Code or any Python-supported IDE.

3. Navigate to the required lab folder.

4. Run the Python program:

   ```bash
   python filename.py
   ```

### For Jupyter Notebooks

1. Open the required `.ipynb` file.
2. Run it using Jupyter Notebook, JupyterLab, or Google Colab.
3. Execute the cells to view the solutions and outputs.
