## 1. Section B - Problem 1: Sum of All Primes Below N

**File:** `Section_B_Problem_1,_Sum_of_All_Primes_Below_N.ipynb`

### Aim
To calculate the sum of all prime numbers smaller than a given number N using different algorithms and compare their performance.

### Approaches Implemented

**Method 1: Naive Approach**

- Checks every number from 2 to N-1.
- Tests whether each number is divisible by any number from 2 to x-1.
- Adds the number to the total if it is prime.

**Time Complexity:** O(N²)  
**Space Complexity:** O(1)

**Method 2: Square Root Optimization**

- Checks divisibility only up to the square root of the number.
- Skips even numbers greater than 2.
- Reduces unnecessary divisibility checks.

**Time Complexity:** O(N√N)  
**Space Complexity:** O(1)

**Method 3: Sieve of Eratosthenes**

- Creates a Boolean list to mark prime numbers.
- Starts with 2 and marks its multiples as non-prime.
- Repeats the process for the remaining prime candidates.
- Calculates the sum of all numbers still marked as prime.

**Time Complexity:** O(N log log N)  
**Space Complexity:** O(N)

### Test Cases

| Input (N) | Expected Sum |
|---|---:|
| 10 | 17 |
| 30 | 129 |
| 100 | 1060 |
| 1000 | 76127 |

### Concepts Covered

## 2. Section C - Problem 2: Count Pairs With a Given Sum

**File:** `Section_C_Problem_2,_Count_Pairs_With_a_Given_Sum.ipynb`

### Aim
To count the number of distinct pairs in an array whose sum is equal to a given target value.

### Approaches Implemented

**Method 1: Naive Approach**

- Uses two nested loops to examine every possible pair.
- Checks whether the sum of the selected elements equals the target.
- Increments the counter whenever a matching pair is found.

**Time Complexity:** O(N²)  
**Space Complexity:** O(1)

**Method 2: Optimized Approach Using Dictionary**

- Uses a dictionary to store previously encountered numbers and their frequencies.
- Calculates the complement of each element using `target - x`.
- Checks whether the complement already exists in the dictionary.
- Adds the complement's frequency to the pair count.
- Updates the frequency of the current element.

**Time Complexity:** O(N) average  
**Space Complexity:** O(N)

### Performance Testing

The notebook uses randomly generated arrays with a fixed random seed for repeatable testing.

| Approach | Array Size |
|---|---:|
| Naive | 5,000 |
| Naive | 50,000 |
| Optimized | 50,000 |

The execution time of both approaches is measured using Python's `time` module.

## 3. Section D - Problem 3: K-th Smallest Pairwise Sum

**File:** `Section_D_Problem_3,_K_th_Smallest_Pairwise_Sum_.ipynb`

### Aim
To find the K-th smallest sum generated by adding two distinct elements of an array and compare a naive solution with an optimized algorithm.

### Approaches Implemented

**Method 1: Naive Approach**

- Generates all possible pairwise sums using two nested loops.
- Stores the generated sums in a separate list.
- Sorts the list in ascending order.
- Returns the element at position K-1.

**Time Complexity:** O(N² log N)  
**Space Complexity:** O(N²)

**Method 2: Optimized Approach**

The optimized solution uses sorting, two pointers, and binary search on the possible sum values.

It consists of two main operations:

1. `count_pairs_leq(arr, v)`
   - Uses two pointers to count the number of pairs whose sum is less than or equal to a given value.
   - Avoids generating and storing every pairwise sum.

   **Time Complexity:** O(N)  
   **Space Complexity:** O(1)

2. `kth_smallest_sum_optimized(arr, k)`
   - Sorts the input array.
   - Determines the minimum and maximum possible pair sums.
   - Applies binary search over the possible sum range.
   - Uses the pair-counting function to determine whether the middle value can contain at least K pair sums.

   **Time Complexity:** O(N log N + N log V)  
   **Space Complexity:** O(N)

   Here, V represents the range of possible pairwise sum values.

### Performance Testing

The notebook generates an array using a fixed random seed.

| Parameter | Value |
|---|---:|
| Array Size (N) | 5,000 |
| K | 1,000,000 |
| Random Number Range | 1 to 100,000 |
