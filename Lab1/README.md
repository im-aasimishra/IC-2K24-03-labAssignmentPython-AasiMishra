
# Lab 1 – Introduction to Python Programming

This folder contains Lab 1 assignments for the subject **Python Programming**. It covers basic Python concepts, expressions, operators, variables, data types, input/output operations, string manipulation, and simple programming exercises.

The purpose of this lab is to understand Python fundamentals through practical implementation.

## Section A – Basic Python Concepts

**File:** `sectionA.txt`

This file contains theoretical questions and answers related to Python fundamentals, including:

- Use of the `input()` function.
- Understanding the `type()` function.
- Type conversion using `int()` and `float()`.
- Arithmetic operators such as `**`, `//`, and `%`.
- Python comments using `#`.
- Rules for naming variables and identifiers.

## Section B – Expressions and Output

**Files:** `SectionB.txt` and `SectionB.py`

This section focuses on evaluating Python expressions and understanding their outputs.

Topics covered:

- Arithmetic expressions.
- Modulus and exponentiation operators.
- Boolean expressions and comparisons.
- Data types and type checking.
- String slicing.
- Escape sequences such as `\t` and `\n`.

## Section C – Python Practical Programs

The following programs demonstrate the practical implementation of Python concepts.

| File Name | Description |
|---|---|
| `variableIdentifier.py` | Demonstrates variables, identifiers, and data types. |
| `greetingsP.py` | Accepts user details and displays a formatted greeting using f-strings. |

## How to Run the Programs

### Requirements

- Python 3.x installed on your system.
- Any Python-compatible code editor (VS Code, PyCharm, IDLE, etc.).

### Execution

Open the terminal in the `Lab1` directory and execute the programs using:

```bash
python3 variableIdentifier.py
python3 greetingsP.py
python3 arethematicOp.py
python3 tempConversion.py
python3 stringManipulation.py
python3 SectionB.py
python3 escapeSequence
python3 calculator2.py
```
